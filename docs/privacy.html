تطبيق: نظام الفحص — الفروانية
آخر تحديث: 11 مايو 2026

نحرص في تطبيق نظام الفحص على حماية خصوصية المستخدمين. توضّح هذه السياسة طبيعة البيانات التي يجمعها التطبيق وكيفية استخدامها.

1. البيانات التي نجمعها

  • بيانات الحساب: اسم المستخدم، الدور الوظيفي (موظف / ضابط فحص / إداري)، ومعرّف الموظف.
  • بيانات العمل: سجلات الحضور والانصراف، تقارير الفحص، الإشعارات الإدارية.
  • الإشعارات: رمز جهاز الإشعارات (FCM Token) لإرسال الإشعارات الفورية فقط.
  • بيانات تقنية: نوع الجهاز ونظام التشغيل لأغراض تشغيل التطبيق فقط.

2. كيف نستخدم البيانات

  • إدارة حسابات الموظفين وعرض البيانات الخاصة بكل مستخدم حسب صلاحيته.
  • تسجيل الحضور والانصراف وعرض التقارير الإدارية.
  • إرسال إشعارات تتعلّق بالعمل (تذكير بالحضور، تنبيهات إدارية).
  • تحسين أداء التطبيق وحلّ المشاكل التقنية.

3. مشاركة البيانات

لا نبيع أو نؤجّر بياناتك لأي طرف ثالث. تُخزَّن البيانات على الخدمات التالية التي تلتزم بمعايير الأمان:

  • Supabase — قاعدة بيانات وتشفير الجلسات.
  • Firebase Cloud Messaging (Google) — لإرسال الإشعارات.

4. حماية البيانات

نستخدم تشفير HTTPS لجميع الاتصالات، وصلاحيات وصول مقيّدة (Row Level Security) لضمان عدم وصول أي مستخدم لبيانات لا تخصّه.

5. حقوق المستخدم

  • طلب نسخة من بياناتك.
  • طلب تصحيح أو حذف بياناتك.
  • سحب الموافقة على استلام الإشعارات في أي وقت من إعدادات الجهاز.

6. الأطفال

التطبيق مخصص لاستخدام الموظفين البالغين فقط ولا يستهدف الأطفال دون 13 عامًا.

Privacy Policy

App: Farwaniya Inspection System
Last updated: May 11, 2026

This Privacy Policy describes how the Farwaniya Inspection System app collects, uses, and protects your information.

1. Information We Collect

  • Account data: username, role (employee / inspector / admin), and employee ID.
  • Work data: attendance records, inspection reports, administrative notifications.
  • Push notifications: FCM device token used solely to deliver notifications.
  • Technical data: device type and OS version for app operation.

2. How We Use the Data

  • Manage employee accounts and display authorized data per user role.
  • Record attendance and generate administrative reports.
  • Deliver work-related push notifications.
  • Improve performance and troubleshoot issues.

3. Data Sharing

We do not sell or rent your data. Data is stored on the following providers that comply with industry security standards:

  • Supabase — database and session encryption.
  • Firebase Cloud Messaging (Google) — push notifications.

4. Data Protection

All communications use HTTPS encryption. Row Level Security policies restrict access so users can only access data they are authorized to view.

5. Your Rights

  • Request a copy of your data.
  • Request correction or deletion of your data.
  • Disable notifications at any time from device settings.

6. Children

The app is intended for adult employees only and is not directed at children under 13.
